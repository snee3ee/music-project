# Music Project

Локальное приложение для технического анализа аудио, аудита музыкальной библиотеки,
поиска дубликатов и проверки архивов. Исходные аудиофайлы не изменяются.
Версия **0.2.5.dev0 — CUE / SACD ISO и ясные результаты**. Разработка; v1 не объявлена.

Постоянный стандарт: **ONLY FACTS. NO OPINIONS.** Измерение, техническая проверка,
расчёт и вывод по правилу имеют разные значения. Неопределённость не заменяется
рейтингом качества или утверждением об исторической аутентичности.

Добавлено исследование предыдущего lossy-кодирования для обычных lossless PCM,
включая FLAC16/44,1: энергия полос, адаптивные спектральные переходы и повторяемость
по каналам/времени. Результат и область — в Origin Investigator; численные
свидетельства — в Экспертном режиме. Измеренный спад не устанавливает MP3/AAC-историю,
а проверенный FLAC MD5 не подтверждает lossless-происхождение.
[Методика](docs/LOSSY_METHODOLOGY.md) · [106контролей, реальные измерения и инструкции](docs/LOSSY_VALIDATION.md).

## Анализ файла: модули результатов

Результат показан первым, объяснение — кратко, доказательства доступны по запросу.
В обзоре — компактное описание файла, статус проверки, статус происхождения и
Integrated / True Peak / LRA. Подробные выводы имеют одно основное место:
«Целостность», «Спектр и уровни» или Origin Investigator. Таблицы правил, точные
числа, backend, методология и исходные сообщения находятся только в техническом приложении.

По умолчанию референс не выбран. Пользовательский LUFS/True Peak референс включает
расчёт gain и проверку потолка; исходный файл не изменяется. Переключение референса,
режима или графика использует сохранённые измерения.

В **Обычном режиме** показаны основные факты; **Экспертный режим** добавляет численные
свидетельства, спектры и альтернативные объяснения. Оба режима используют одну навигацию:
**Обзор → Целостность → Спектр и уровни →
Origin Investigator → DSD Diagnostics → Техническое приложение**. DSD-модуль появляется
только для DSD, остальные модули — при наличии соответствующих результатов.
Переключение читает сохранённые результаты и не запускает декодирование повторно.
PCM-спектр и спектрограмма кэшируются отдельно.

Обзор показывает компактное описание источника и фактические выводы. «Целостность» показывает область проверки
и интервалы; источники длительности и вторичные оценки сохранены в техническом приложении.
Одинаковые предупреждения объединены с сохранением
числа событий. В «Спектр и уровни» показаны измерения с указанными единицами и областью.
Origin Investigator показывает фактические границы, шумовые переходы и оценённые гипотезы.
Команды, исходные предупреждения, полные PSD/quantization-данные, методология и JSON
экспорт находятся в техническом приложении. Параметры запуска свёрнуты отдельно.

Предыдущая проверка представления без изменения DSP и версии:
[Results first](docs/UI_RESULTS_FIRST_VALIDATION.md).
Предыдущая структура и реальные результаты DSD256:
[исторический отчёт интерфейса](docs/ANALYZE_UI_VALIDATION.md).

Инженерная проверка 2026-11-11: исправлены пропуски проверки структуры DFF,
выбор спектрального кандидата, проверка 16-bit grid при периодическом сигнале и
выход измерения громкости за область начального фрагмента. FLAC MD5 проверен на
8/16/24/32-bit контрольных файлах. Версия приложения остаётся 0.2.5.dev0; методы
обновлены с инвалидацией кэша. [Матрица, реальные DSF/CUE/ISO и команды](docs/V1_VALIDATION_MATRIX.md).

## Изменения 0.2.5.dev0

- Вверху результата — имя, отдельно контейнер и кодек, частота, применимая разрядность,
  каналы и выбранная длительность. Затем выводы; свидетельства и методология доступны по запросу.
- CUE: выбор дорожки однофайлового или многофайлового альбома, INDEX 01/00 и 75 кадров/с,
  Unicode и выбор кодировки, независимая проверка формата ссылки. `FILE *.dff WAVE`
  не считается PCM по слову WAVE. Пропущенные, неоднозначные и внешние ссылки имеют разные статусы.
- Логическая дорожка анализируется в своём интервале; времена результатов — от её начала,
  смещение в исходнике сохранено. Временный WAV/DSF содержит только выбранную дорожку и удаляется.
- SACD ISO: проверка структуры, области и список дорожек через совместимый optional
  `sacd_extract`; выбор и анализ одной native DSD дорожки. FFmpeg не подменяет ISO extractor.
- Реальные Aja CUE/DFF и stereo DSD64 ISO проверены по явно разрешённым локальным путям.
  Дорожки перечислены и обработаны; равенство аудио/мастеринга между DFF и ISO не утверждается.

Методы и ограничения: [CUE / SACD](docs/CUE_SACD_METHODS.md).
Фактические дорожки, backend, тесты и SHA-256: [отчёт проверки](docs/CUE_SACD_VALIDATION.md).
Backend не загружается приложением автоматически: укажите путь в «Настройках».
Для этой локальной проверки portable-backend установлен в игнорируемую `data/backends/`
по отдельному разрешению владельца. Реальный DST и многоканальное SACD-аудио не валидированы.

## Проверка реального DSD256

1. Запустите `Music_Project.bat` или `.venv\Scripts\python.exe -m streamlit run app.py`.
2. Откройте **Анализ файла → Выбрать файл…**, укажите собственный
   `02. The Pink Panther DSD 256fs - 2ch.dsf`. Приложение не ищет его автоматически.
3. В **Параметры анализа** выберите **Quick Analysis**, **352.8 kHz**, нажмите **Анализировать**.
   Переключитесь в **DSD Diagnostics** и **Целостность**: проверьте интервалы, контейнер и спектр.
4. Для проверки целого потока выберите **Full Analysis**, повторите анализ.
   Только Stream Integrity = Passed и `complete_file=true` подтверждают завершение
   декодирования всего потока в этой проверке. Внимательно прочитайте предупреждения.
5. В **Техническое приложение** сравните DSF sample count/native rate, ffprobe duration и длительность
   декодированного PCM; сохраните JSON из **Технического приложения**. При расхождении с foobar2000 учитывайте
   padding, округление и версии декодеров. Разница сама по себе не доказывает повреждение.
6. При необходимости повторите на **176.4 kHz**; кэш разделяет эти параметры.
   Энергия ультразвука зависит от преобразования. Характеристика native DSD не валидирована.

Для локального opt-in end-to-end теста, без автоматического поиска файлов:

```powershell
$env:MUSIC_PROJECT_DSD_FIXTURE = 'D:\ваша-папка\02. The Pink Panther DSD 256fs - 2ch.dsf'
.venv\Scripts\python.exe -m pytest tests/test_dsd.py -k real_dsd256 -q
Remove-Item Env:MUSIC_PROJECT_DSD_FIXTURE
```

Без этого пути тест пропускается. Предоставленный владельцем Pink Panther DSD256
теперь проверен локально: Full завершён на обеих частотах PCM; sample count и декодирование
дают 234.026667 s, а оценка ffprobe — 235.881361 s. Источники и ограничения описаны в отчёте интерфейса.
Синтетические DSF DSD64/128/256 и DFF проверены настоящим FFmpeg 9.0.2; это не валидация
исторической аутентичности. DST, multichannel spectra и SACD extraction не поддержаны.

## Установка и запуск на Windows

Требуются Python 3.13+, FFmpeg и ffprobe в PATH либо настроенные пути к ним.
Бинарные backends не скачиваются приложением. Устанавливайте их из доверенных источников.

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.venv\Scripts\python.exe -m streamlit run app.py
```

Для editable-установки с `--no-build-isolation` нужен setuptools; он зафиксирован в lock-файле.
Альтернатива без lock: `.venv\Scripts\python.exe -m pip install -e ".[dev]"`.
Lock фиксирует установленный набор для Windows/Python 3.13, без хешей артефактов.
Для других платформ и версий Python может потребоваться разрешение зависимостей заново.

В этом окружении `.venv` уже создана. Если `python` / `py` указывает на неработающий
WindowsApps alias, укажите путь к реальному Python. Здесь обнаружен
`C:\Users\kalos\AppData\Local\Python\pythoncore-3.13-64\python.exe`.

Двойной щелчок по **Music_Project.bat** запускает проектную `.venv`, проверяет зависимости
и запускает Streamlit. Откройте **http://127.0.0.1:8501**.
Адрес ограничен loopback, сбор статистики Streamlit отключён в проектной конфигурации.
Настройки backend в интерфейсе действуют до завершения сессии.

## Что работает

- **Обзор:** размер, длительность, артисты, папки/альбомы, кодеки, частоты, разрядности,
  DSD, ошибки и группы дубликатов из последнего индекса.
- **Анализ файла:** реальные метаданные ffprobe, полный LUFS/LRA/True Peak,
  Sample Peak/RMS/crest фрагмента, спектрограмма, осторожные спектральные признаки,
  сетка 16→24 и статистика младшего байта. Подробности свёрнуты по умолчанию.
- **Библиотека:** рекурсивный SQLite-индекс, size+mtime_ns incremental scan,
  полный пересчёт по запросу, SHA-256, full decode, обработка ошибок отдельных файлов,
  базовые замечания к тегам и различиям внутри папки/альбома.
- **Дубликаты:** полное совпадение байтов и отдельно совпадение canonical integer PCM.
  Категории пересекаются. Суммы экономии между категориями не складываются.
- **Архив:** переносимый SHA-256-манифест всех обычных файлов выбранной папки,
  проверка Unchanged / Modified / Hash mismatch / Missing / New / Unreadable.
- **Сравнение:** одинаковые sample rate/channels/layout, целочисленное выравнивание,
  gain, polarity, correlation и остаток после компенсации, если выравнивание достаточно надёжно.
- **Специальные входы:** DSF/DFF metadata, DSD diagnostics и отдельная DSD-маршрутизация,
  CUE metadata/INDEX validation, SACD/ISO9660 signature inspection.
- **Инструменты:** проверка ограничений пользовательского профиля устройства.
- **Отчёты:** загрузка JSON в браузере без изменения исходников.

PCM-спектр и квантование по умолчанию анализируют первые 30 секунд (лимит буфера 128 MiB).
Точная область показывается в отчёте. LUFS/LRA/True Peak и хеши обрабатывают весь первый
аудиопоток с настраиваемым тайм-аутом. Preview создаёт браузерное WAV-представление фрагмента.
Это не bit-perfect player.

## Что пока не реализовано

Акустическая группировка Chromaprint, онлайн-идентификация, watch folders,
альбомное mastering comparison, дробное выравнивание/clock drift/resampling comparison,
исполнение конвертаций и исправлений тегов, воспроизведение логических CUE-треков,
native DSD provenance classification, полноценный SACD TOC/track listing/extraction и лицензирование продаж.
Для SACD есть проверяемый план команды; его исполнение не подключено к UI.
Никакой SACD end-to-end успех не заявляется.

## Хранение и приватность

Индекс — `data/library.sqlite3`, исключён из Git. Сохраняет пути, теги, технические
свойства, хеши и ошибки. Полные forensic-отчёты пока не сохраняются в индексе.
Нет аккаунта, сетевой идентификации или загрузки аудио. Сервер предназначен для одного
локального пользователя. Декодерам разрешены только `file,pipe` протоколы.
Рекурсивный обход исключает symlinks/junctions; исходные ISO не копируются.
Манифест храните **вне** проверяемого дерева, иначе сам манифест появится как New.

Системный выбор файла использует установленный Windows PowerShell и Windows Forms
в режиме STA. Дополнительные программы не устанавливаются. При недоступности окна
или истечении 5 минут можно вставить путь вручную. На других ОС доступен ввод пути.

```powershell
.venv\Scripts\python.exe -m pip check
```

Тесты создают маленькие синтетические файлы во временной папке, не используют коллекцию пользователя.
Реальные SACD integration tests явно пропущены до появления backend и fixture.
AppTest проверяет логику интерфейса; визуальная проверка в реальном браузере не выполнена.

## Диагностика

- **Backend unavailable:** настройте точный executable в «Настройки» или исправьте PATH.
- **Тайм-аут:** увеличьте его для длинных файлов; это не подтверждение повреждения.
- **Unknown / Ambiguous:** недостаточно данных или специфичности метода, а не ошибка оценки.
- **Unreadable/unsupported:** смотрите диагностику: отсутствие декодера не равно доказанной порче.
- **Unicode/CP1251:** subprocess всегда читает диагностику как UTF-8 с replacement,
  PCM остаётся bytes. Для консольных команд при необходимости используйте `-X utf8`.
- **Не видны изменения файла:** запустите полный пересчёт; incremental доверяет size+mtime_ns.
- **Нет PCM-группы при одинаковой записи:** разные rates/layouts, float/WavPack,
  lossy или обработка не входят в поддержанную точную канонизацию.
