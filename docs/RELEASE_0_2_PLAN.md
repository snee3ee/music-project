# Версия 0.2 — понятные результаты и выбор файла

Согласованный фокус: замечания пользователя к 0.1. Новые продуктовые направления
в этот этап не входят. AGENTS.md, skills и legacy_reference сохраняются.

## План реализации

1. Разделить измеренные признаки и исторические выводы. Показывать обнаружение,
   отсутствие по заданному порогу, нехватку данных и неприменимость отдельно.
2. Добавить проверяемые признаки по существующим измерениям: Cutoff, границы
   Nyquist, PSD в верхних полосах, 16-bit grid и full-scale/True Peak превышения.
   Не устанавливать исторический Source rate или native bit depth без оснований.
3. Заменить Python dict/JSON в обычном интерфейсе таблицами и подписями.
   Русские действия/пояснения, английские инженерные термины и единицы.
4. Добавить системное окно выбора файла Windows; оставить ввод пути как альтернативу.
   Выбирать источник напрямую, не копировать большие файлы и не загружать аудио на сервисы.
5. Проверить алгоритмы положительными, отрицательными и неоднозначными контролями;
   проверить форматирование и пользовательские действия через AppTest.
6. Обновить версии, методологию и результаты фактически выполненных проверок.

## Последующие версии в рамках этих замечаний

- **0.2:** измеренные признаки отдельно от выводов; понятный русский интерфейс;
  английские термины; системный выбор файла. Реализовано, проверки ниже.
- **0.3:** дальнейшая проверка существующих Cutoff/Upsampling/Bit-depth методов
  на дополнительных контролях и доступных записях; сужение неопределённости только
  при наличии проверяемых оснований. Без новых продуктовых модулей.
- **0.4:** уточнение этих же экранов по результатам использования 0.2/0.3.
  Конкретные изменения определяются замечаниями пользователя, не добавляются заранее.

## Проверки

- Полный pytest: **126 passed, 0 failed, 1 skipped**, 16.65 s. Пропуск — прежний
  реальный SACD integration test без fixture/backend; к задачам 0.2 он не относится.
- Ruff check и format check, compileall, pip check выполнены успешно.
- После уточнения ошибок диалога повторно выполнены File picker/UI тесты: 25 passed.
- AppTest: восемь страниц, анализ, Spectrum/Preview, выбор файла без вставки пути,
  отмена выбора, пустой/несуществующий путь, сканирование и сравнение.
- Windows Forms: фактически созданы и освобождены OpenFileDialog, проверены синтаксис
  реального PowerShell-обработчика и Unicode JSON. Ручной выбор в открытом окне и
  визуальная проверка браузера не выполнены; AppTest подменяет ответ диалога.
- Признаки проверены на broad-band, sharp-resampling, silence, short, tone,
  Padding/Gain и True Peak positive/negative/zero controls.
- README и методология обновлены. Устанавливается версия 0.2.0, метод 2026.10-v2.

Системный диалог использует Windows PowerShell + Windows Forms без новых зависимостей.
Tcl/Tk в этом окружении не запускается; в рабочем маршруте он не используется.
Старые исторические статусы сохранены отдельно от измеренных признаков, пороги
подозрения не ослаблены. Реальные записи для расширенной валидации не использовались.
