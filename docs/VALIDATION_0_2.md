## Контроли признаков

Broad-band PCM: Cutoff/Nyquist boundary не обнаружены по порогам; Median PSD верхних
полос выше порога. Историческая Source rate по-прежнему Unknown, отдельным полем.

Sharp FFT resampling 44.1/48→96 kHz: обнаружена Nyquist boundary; Median PSD выше
25 kHz ниже порога. Полоса 22.3–23.7 kHz различается между этими синтетическими
контролями, но это не распространяется на произвольную историю записи.

Silence/short/tone: недостаток данных для границы не превращается в отрицательное
обнаружение. При низкой Sample rate Cutoff корректно Not applicable. При 50 kHz
не используется неполная полоса вокруг 24 kHz. На 44.1 kHz явно проверяются границы
14–20 kHz, без заявления о проверке 21 kHz.

16-bit grid: обнаружение прямой сетки и отсутствие после Gain проверены отдельно.
Full-scale samples не интерпретируются как доказанное Clipping.

True Peak: положительный inter-sample over, отрицательный контроль и нулевой сигнал
прошли FFmpeg integration tests. Отдельный тест подтверждает, что NaN из backend
остаётся недостатком данных, а не отсутствием превышения. `−∞` и отсутствующее
значение различаются в JSON состоянием и в UI подписью. Аналогично различаются
нулевой Residual RMS и отсутствие интерпретации из-за ненадёжного Alignment.
